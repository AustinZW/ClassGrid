# 课格 ClassGrid 产品说明

## 用户目标

学生可以在没有网络的情况下快速建立课表，按教学周查看当天课程，并可靠地处理单双周与不连续周次。

## 核心流程

1. 首次打开应用，默认以本周一作为学期开始日期。
2. 用户在“学期设置”中调整名称、开学日期、总周数和每日节数。
3. 用户点击添加课程，填写课程、时间和周次并保存。
4. 首页根据选中周次过滤课程；点击课程可以编辑或删除。

## 业务规则

- 星期取值为 1–7，对应周一至周日。
- 节次取值为 1–每日节数，结束节次不得早于开始节次。
- 周次最终保存为明确的整数集合，以兼容单双周和任意不连续周。
- 当前周由开学日期按每 7 天计算，范围限制在第 1 周到学期总周数。
- 数据默认仅保存在设备本地；卸载应用可能清除数据。

## 验收标准

- 课程增删改后无需重启即可反映在当前周。
- 重启应用后课程与学期设置仍保留。
- 每周、单周、双周及自定义周次过滤结果正确。
- 不允许保存空课程名、越界节次或空的自定义周次。
- 删除课程前出现二次确认。
- 系统深色模式切换后界面仍可读。
- 第 1 周与最后一周不能继续向范围外切换。
