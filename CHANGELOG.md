# Changelog

All notable changes to ClassGrid are documented in this file.

## [1.0.0] - 2026-09-23

### Added

- Material 3 weekly timetable with date and teaching-week navigation
- Flexible class days, section counts, class times, cell height, and typography settings
- Multi-slot courses with custom weeks, rooms, teachers, notes, and colors
- Course creation, editing, copying, dragging, and duration resizing
- Conflict detection and interactive conflict resolution
- Import from Donghua University's undergraduate academic system
- Portable `.cgf` timetable import and export
- First-run setup, dark mode, and dynamic colors

### Changed

- Adjacent compatible course sections are merged automatically
- Settings and course appearance controls update and save automatically
